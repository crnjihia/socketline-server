# Contributing to Socketline Server

We welcome contributions! Please follow these guidelines:

- Fork the repository and create a feature branch.
- Write clear, descriptive commit messages following the project's commit style.
- Ensure the code builds with all CMake presets (`debug`, `release`, `asan`, `tsan`).
- Run the test suite (`ctest --preset <preset>`) and ensure all tests pass.
- Add or update documentation as needed.
- Submit a pull request with a concise description of your changes.
